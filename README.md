# dd1-tools
Tools for messing with DD1 flash images

## inject_smc.py

Used to inject a clean Xenon 1.51 SMC and an SMC config in to a DD1 NAND image. Tested on 1838 and 1640.

Gives you proper fan control and wireless controller support, at least on a franken-XeDK made by attaching a DD1 CPU to a final Xenon board
